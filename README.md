# employee-salary-calculation

Python project for calculating employee salary with HTML interface.

## Python code

Run the Python script:

```bash
python salary_calculator.py --name "John" --basic 50000 --allowance 4000 --pf 2000 --tax 1500
```

## HTML code

Open `index.html` in a browser to use the calculator in a simple web page.

## Output example

```text
Employee Name: John
Basic Salary: 50000.00
Allowance: 4000.00
Gross Salary: 54000.00
PF Deduction: 2000.00
Tax Deduction: 1500.00
Total Deductions: 3500.00
Net Salary: 50500.00
```
